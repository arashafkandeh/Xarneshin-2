# زرنشین - پنل مدیریت پیشرفته Xray برای مرزنشین

**زرنشین** یک ابزار قدرتمند و مدرن مبتنی بر فلسک است که شامل یک **رابط وب** و **ابزار خط فرمان (CLI)** برای مدیریت یکپارچه تنظیمات Xray در کنار سیستم مدیریت پراکسی [مرزنشین](https://github.com/marzneshin/marzneshin) می‌باشد. این پنل با ارائه قابلیت‌های منحصر به فردی مانند نصب نود از راه دور، مدیریت جامع کانفیگ Xray و رابط کاربری زیبا، تجربه مدیریت سرور را متحول می‌کند.

---

## معماری پروژه

زرنشین از یک معماری دوگانه هوشمند برای مدیریت نودها استفاده می‌کند:

1.  **حالت API (API Mode):** برای مدیریت تنظیمات داخلی Xray مانند **اینباندها، اوتباندها، DNS و قوانین مسیریابی**، زرنشین به عنوان یک کلاینت برای API پنل مرزنشین عمل می‌کند. تمام درخواست‌های مربوط به کانفیگ از این طریق ارسال می‌شوند.

2.  **حالت دسترسی مستقیم (Direct Access Mode):** برای عملیات‌های سیستمی و مدیریتی سطح بالا، زرنشین مستقیماً و بدون واسطه API مرزنشین عمل می‌کند:
    *   **SSH (Paramiko):** برای **نصب کامل مرزنشین روی یک سرور جدید**، تغییر نسخه هسته Xray روی نودهای ریموت، و اجرای دستوراتی مانند ریبوت.
    *   **Sudo:** برای اجرای دستورات با دسترسی ریشه روی نود محلی (local)، مانند تغییر نسخه هسته Xray یا پاک‌سازی کش سیستم.
    *   **پایگاه داده محلی:** زرنشین از یک پایگاه داده SQLite در مسیر `data/installed_nodes.db` برای ذخیره اطلاعات اتصال SSH نودهایی که از طریق پنل نصب شده‌اند، استفاده می‌کند.

این معماری به زرنشین اجازه می‌دهد تا علاوه بر مدیریت کانفیگ، قابلیت‌های مدیریتی عمیق‌تری را نیز فراهم کند.

## ✨ ویژگی‌های کلیدی

### رابط وب (Web UI)

- **داشبورد مدرن:** رابط کاربری واکنش‌گرا و زیبا با فریمورک Tailwind CSS برای مدیریت تمام جنبه‌های Xray.
- **نصب نود از راه دور:** قابلیت نصب کامل پشته مرزنشین (Marznode) روی یک سرور خام تنها با وارد کردن اطلاعات SSH. خروجی نصب به صورت **زنده (real-time)** در پنل نمایش داده می‌شود.
- **مدیریت جامع کانفیگ:**
    - مدیریت کامل **اینباندها، اوتباندها، قوانین مسیریابی، DNS و بالانسرها**.
    - **ویرایشگر پیشرفته:** یک ویرایشگر JSON برای مشاهده و تغییر مستقیم تمام کانفیگ Xray.
- **مدیریت نسخه هسته:** امکان تغییر نسخه هسته Xray برای **نود محلی و نودهای ریموت**.
- **ابزارهای کمکی:**
    - **تست اتصال:** ابزاری برای بررسی صحت اطلاعات اتصال SSH و پروکسی **قبل از شروع فرآیند نصب**.
    - **تولیدکنندگان (Generators):** ابزارهای داخلی برای تولید کلیدهای `REALITY`، گواهی‌های TLS خودامضا (Self-Signed) و کانفیگ `WARP`.
- **مدیریت سیستمی:** اجرای دستوراتی مانند **ریبوت کردن سرور** یا **پاک‌سازی کش رم** از راه دور.
- **عملیات گروهی:** قابلیت ریستارت کردن هسته Xray روی تمام نودها به صورت همزمان.

### ابزار خط فرمان (CLI)

یک ابزار خط فرمان قدرتمند به نام `xarneshin` برای مدیریت سریع و آسان:

- **مدیریت سرویس:** مشاهده وضعیت، ریستارت و حذف کامل زرنشین.
- **پیکربندی شبکه:** تغییر پورت‌های پنل زرنشین و پنل مرزنشین.
- **مدیریت HTTPS:** فعال‌سازی و غیرفعال‌سازی HTTPS برای دسترسی به پنل زرنشین.
- **پروتکل پنل:** تنظیم پروتکل ارتباطی با پنل مرزنشین (HTTP یا HTTPS).
- **به‌روزرسانی فایل‌های Geo:** دانلود آخرین نسخه‌های فایل‌های `geoip.dat` و `geosite.dat`.

## 📦 نصب

نصب زرنشین به طور کامل توسط اسکریپت `install.sh` انجام می‌شود. این اسکریپت تمام وابستگی‌ها را نصب، سرویس systemd را ایجاد و ابزار CLI را راه‌اندازی می‌کند.

### پیش‌نیازها

- یک سرور با سیستم‌عامل Debian یا Ubuntu.
- پایتون 3.6+
- نصب بودن پنل **مرزنشین**.

### مراحل نصب

دستور زیر را در ترمینال سروری که پنل مرزنشین روی آن نصب است، اجرا کنید:

```bash
git clone https://github.com/arashafkandeh/Xarneshin-2.git ~/Xenon.xray && cd ~/Xenon.xray && chmod +x install.sh && sudo ./install.sh
```

پس از اتمام نصب، وضعیت سرویس را بررسی کنید:

```bash
sudo systemctl status xarneshin.service
```

شما می‌توانید از طریق آدرس `http://<IP-سرور>:<پورت-فلسک>` به رابط وب دسترسی پیدا کنید (پورت پیش‌فرض `42689` است).

**🔑 توجه: نام کاربری و رمز عبور برای ورود به پنل زرنشین، با نام کاربری و رمز عبور ادمین پنل مرزنشین شما یکسان است.**

### (اختیاری) فعال‌سازی HTTPS

برای ایمن‌سازی پنل زرنشین با SSL، دستور زیر را اجرا کرده و گزینه **7 (Configure HTTPS Settings)** را انتخاب کنید:
```bash
xarneshin
```

## 🚀 نحوه استفاده

### استفاده از رابط وب

- **ورود:** با اطلاعات ادمین مرزنشین وارد شوید.
- **مدیریت نودها:** از منوی اصلی، نود مورد نظر خود را برای مدیریت انتخاب کنید.
- **نصب نود جدید:** از بخش "Node Installer"، یک سرور جدید را با وارد کردن اطلاعات SSH نصب کنید.
- **ویرایش کانفیگ:** در صفحه هر نود، به بخش‌های مختلف مانند Inbounds, Outbounds, DNS و... برای ویرایش تنظیمات بروید.

### استفاده از ابزار خط فرمان (CLI)

برای دسترسی به منوی مدیریتی، دستور `xarneshin` را در ترمینال وارد کنید.

| دستور         | توضیحات                                                                   |
|---------------|----------------------------------------------------------------------------|
| `status`      | نمایش وضعیت سرویس زرنشین و زمان فعالیت (uptime).                           |
| `change-ports`| تغییر پورت دسترسی به پنل زرنشین یا پورت پنل مرزنشین.                         |
| `update-geofiles`| دانلود و به‌روزرسانی فایل‌های `geoip.dat` و `geosite.dat`.                 |
| `restart`     | راه‌اندازی مجدد سرویس زرنشین.                                              |
| `show-address`| نمایش URL کامل برای دسترسی به پنل وب.                                      |
| `uninstall`   | حذف کامل زرنشین، سرویس و فایل‌های مرتبط.                                  |
| `Configure HTTPS`| فعال‌سازی HTTPS برای پنل زرنشین با ارائه دامنه و فایل‌های گواهی.           |
| `Configure Panel Protocol`| تنظیم نوع ارتباط با API مرزنشین (HTTP یا HTTPS).               |

## 📁 ساختار پروژه

```
/
├── assets/             # اسکریپت‌های کمکی (نصب نود، تغییر نسخه Xray)
├── data/               # پایگاه داده SQLite برای ذخیره اطلاعات نودها
├── modules/            # ماژول‌های اصلی برنامه (منطق نودها، بازبینی و...)
├── static/             # فایل‌های ثابت وب (CSS, JS, تصاویر)
├── templates/          # قالب‌های HTML برای رابط وب
├── install.sh          # اسکریپت نصب و ابزار CLI
├── xenon.py            # فایل اصلی اپلیکیشن Flask
└── ports.json          # فایل پیکربندی پورت‌ها و تنظیمات شبکه
```
